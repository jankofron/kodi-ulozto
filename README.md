# kodi-ulozto
Addon for playing video files stored on a private [Uloz.to Disk](https://uloz.to). Only **Kodi 21** is supported at the time.

# Installation
1. Download the Kodi-ulozto repository zip file: [ulozto-repository-kodi21.zip](https://github.com/jankofron/kodi-ulozto/blob/main/ulozto-repository-kodi21.zip).
2. Run Kodi, go to Settings and enable installation from unknown sources.
3. Enter the Addon browser, choose install from zip and select the downloaded file.
4. Install the ulozto addon from the newly added repository. It will be automatically updated unless you disable this in the KODI main settings.
4. Open the plugin settings and fill in the login info. You will need to contact Uloz.to support to get your X-Auth-Token (in Czech: API klíč) that is required for accessing your files.
5. You need to select the root folder whose content will be displayed.
6. If you want to scrape recordings info from TMDB, you need your own TMDB API key. The key is for free, you just need an account at TMDB. The key is quite long, so store it to a file, and select the file in the addon settings.
